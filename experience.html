Auryn Callista Luftyansa

The first step I took before diving into the code was designing the user interface (UI/UX). Using Figma—one of my core skills with around 75% proficiency—I crafted a clean layout dominated by a signature blue color scheme and a bright background. I mapped out the page structure, which includes a Hero Section (Name Header), About Me, Skills, Projects, and Contact Me. Once the design was ready, I began transforming it into code. I built the foundational structure of the website using HTML5. At this stage, I wrote my profile text as a student born in Boyolali, organized the navigation menu, added my photo, and set up the form structure for the contact section. To bring the layout to life and match the Figma blueprint, I applied CSS to style the text into its signature dark blue color, ensure a responsive design, and style the percentage progress bars for my skill indicators (Figma 75%, HTML 60%, CSS 50%, GitHub 45%). Additionally, I integrated JavaScript to add animations to my website. In the Project section, I linked several works I worked hard on throughout this semester. I featured five main projects: a waste recycling website titled "Pikirkan Sebelum Membuang" (Think Before Throwing Away), a School Web Management System, an Environmental Web, Empowering Brands, and a fashion website named Shmtcha. Everything is neatly organized and complete with action links so visitors can directly view the live results. The final step in creating this website was deployment. Utilizing version control through Git and GitHub, I uploaded all the source code—including index.html, CSS files, and image assets—into a GitHub repository. Afterward, I activated the GitHub Pages feature so that this Semester 2 portfolio project could be accessed by the public on the internet. Through the process of building this "Kolab Sem 2" portfolio website, I have not only successfully documented my learning outcomes but also sharpened my programming logic and UI/UX design skills in a practical way. This project marks the initial step of my journey in the Software and Game Development (PPLG) field to achieve my dream of becoming a competent software developer in the future.
